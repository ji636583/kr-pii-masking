# kr-pii-masking
KLUE-RoBERTa 기반 한국어 개인정보 탐지·마스킹 프로젝트 (오픈소스기초설계 팀 프로젝트)

## 웹 초안

저장소 루트에서 아래 명령을 실행한 뒤 [로컬 데모](http://localhost:8000/)를 엽니다. 별도 패키지 설치는 필요 없습니다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory web
```

`web/`에서는 합성 제안요청서의 원문과 마스킹 결과를 나란히 볼 수 있습니다. 문서를 편집한 뒤 마스킹을 다시 실행하면 탐지된 구간을 유형별 태그로 표시합니다. 입력은 브라우저 메모리에서 처리합니다.

이름은 `이름`, `성명`, `담당자`, `담당자명`, `신청인`으로 표시된 한글 이름을 찾습니다. 모바일 번호와 주민등록번호는 숫자 형식으로 탐지합니다. 데모에서는 합성 문서를 사용합니다.

## 초기 연구 기록

웹의 연구 기준선은 2026-11-26에 정리한 연구 자료의 v3 규칙 단독 집계를 인용합니다. 고정 테스트 110건은 `evidence/v3-cpu/comparison.tsv`의 `rules` 행, 독립 QA 16건은 `evidence/v2-v3-qa/README.md`의 독립 challenge 규칙 행에서 가져왔습니다. 이 두 세트는 입력 분포가 서로 다릅니다. 웹 데모의 평가 점수는 미측정 상태입니다.

정확 스팬 F1은 유형과 위치가 모두 맞은 구간을 기준으로 계산합니다. 미마스킹은 정답 중 가려지지 않은 문자 수, 과마스킹은 정답 밖에서 가려진 문자 수입니다. 독립 QA에서는 정답이 있는 11개 문서 모두에 규칙 기준선이 일부 개인정보를 남겼습니다.

## 팀 저장소 작업 단계

1. **웹 초안** — 원문과 결과 비교, 합성 예시, 브라우저 규칙 데모, 초기 연구 기준선 공유.
2. **규칙 기준선 재현** — 합성 평가 세트와 채점 기준을 정리하고 유형별 오류 집계.
3. **모델 연결과 비교** — KLUE-RoBERTa 탐지 결과를 연결하고 규칙 단독·모델 단독·혼합 방식 비교.
4. **독립 QA** — 고정된 독립 합성 세트에서 미마스킹과 과마스킹을 검토하고 후보 적용 여부 판단.
